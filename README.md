# Simple Web Scraper by _-_EVIL⁶⁶⁶_-_DEV

A beginner-friendly Python web scraper that extracts useful information from any public webpage.

It collects:
- Page title
- Headings (h1–h4)
- All links
- Paragraphs
- Code blocks

Results are saved as both **CSV** and **JSON** files.

---

## Features

- Asks for the target URL when you run it
- Works on any public website
- Saves results automatically with timestamp
- Simple and easy to understand code

---

## Requirements

- Python 3.7 or higher
- `requests`
- `beautifulsoup4`

---

## Installation

### On Termux (Android)

```bash
pkg update && pkg upgrade
pkg install python git
pip install requests beautifulsoup4
```
How to Use

Clone the repository:

```git clone https://github.com/YOUR_USERNAME/web-scraper.git
cd web-scraper
Run the scraper:
python scraper.py
```
When it asks for the URL, paste any public website link (must start with http:// or https://) and press Enter.
Example:
URL: https://example.com
